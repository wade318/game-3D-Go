# game-3D-Go（碁之國）

瀏覽器上的 3D 圍棋沙盤。落下的棋子變成砦，圍住的空地變成插滿旗子的領地。單一 `index.html`，不需要建置。

## 玩法
- 點棋盤交叉點落子；手機要點同一處兩次才會確認。
- 拖曳旋轉視角，滾輪或雙指縮放，按「俯視」切換視角。
- 對手可選電腦（入門 / 普通 / 較強）或雙人同機；棋盤 9 路或 13 路（預設 13 路）。
- 雙方連續跳過兩次即終局，以面積計分，貼目 6.5。終局不會自動移除死子，請先提光。
- 可按「認輸」投子；剛認輸後按「悔棋」可以撤回認輸。
- 電腦中盤認輸：下滿一定手數（9 路 24 手、13 路 40 手）後，若面積落後超過門檻（9 路 10 目、13 路 18 目），且被吃子明顯較多或盤面大致底定，連續兩手都如此就會投子，不會硬撐到終局。

## 特效與天氣
- 圈地：領地從落子處向外擴散、閃光、浮出「+N」。
- 提子：冒煙並噴出碎石。
- 天氣：晴天、多雲、下雨、雷雨、暴風雨、龍捲風（龍捲風會把小鳥捲走）。點左上角的天氣標籤可手動切換。
- 音效用 WebAudio 即時合成，可在底部按鈕開關。

## 本機執行
直接用瀏覽器開 `index.html`，或：

    python3 -m http.server 8000

## 部署到 GitHub Pages
repo 的 Settings → Pages，Source 選 `main` / `(root)`。

## 技術
Three.js r128（cdnjs）、WebAudio、純 JavaScript。電腦對手是蒙地卡羅模擬，在瀏覽器內執行。
